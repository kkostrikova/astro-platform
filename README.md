# VIKTORIA ASTROSTAR — сюрприз-прототип платформи астролога

Це статичний інтерактивний прототип, який можна одразу відкрити у браузері або викласти на GitHub Pages.

## Що вже працює
- темна космічна тема;
- анімовані орбіти, «3D» планети, parallax і рух карток;
- окремий кабінет клієнта;
- окремий кабінет астролога;
- завантаження готової натальної карти, прогнозу, матеріалів консультацій;
- файли зберігаються локально в IndexedDB браузера;
- нотатки зберігаються локально;
- генератор красивого макета прогнозу → системний друк → «Зберегти як PDF»;
- довідник ефемерид із імпортом CSV/JSON, пошуком і фільтрами;
- шаблон CSV для бази ефемерид.

## Важливо
У демо немає вигаданих астрономічних/астрологічних даних. Для ефемерид треба імпортувати перевірену базу подруги (наприклад експорт із її астропроцесора). Це дозволяє не залежати від іншого астропроцесора всередині платформи.

## Як запустити
Найпростіше: відкрити `index.html` подвійним кліком.

Для коректної роботи IndexedDB краще запускати через локальний сервер:

```bash
python -m http.server 8000
```

і відкрити `http://localhost:8000`.

## Для реального багатокористувацького сайту
Наступний етап — підключити backend (наприклад Supabase): Auth, Storage, Postgres/RLS. Тоді клієнт і астролог бачитимуть свої дані з різних пристроїв, а не лише в одному браузері.
